Sobre

Tanakh de Estudo é uma Bíblia Hebraica (o "Antigo Testamento") para estudo do texto original.

Como usar

  • Toque no título no topo para escolher livro → capítulo → versículo.
  • Toque em qualquer palavra hebraica para ver o significado, a raiz, a pronúncia e a definição do léxico.
  • Toque no número do versículo para marcar, anotar, copiar ou compartilhar.
  • Deslize para os lados para trocar de capítulo.
  • As letras sobrescritas (ᵃ ᵇ ᶜ) levam às notas de rodapé no fim do capítulo.
  • Palavras em itálico na tradução foram acrescentadas pelos tradutores e não estão no hebraico.

Fontes

  • Texto hebraico: Westminster Leningrad Codex (Códice de Leningrado, c. 1008 d.C.), com vogais, acentos e números de Strong — domínio público.
  • Léxico: Brown-Driver-Briggs (BDB) e Concordância de Strong.
  • Traduções: fornecidas pela API pública de bolls.life.
  • Notas de estudo: escritas para este app.

A transliteração é gerada automaticamente e é aproximada. A numeração dos versículos hebraicos às vezes difere da numeração em português (ex.: Joel 3 = Joel 4 no hebraico); o app faz essa correspondência automaticamente.
